Este repositorio reúne los laboratorios y actividades desarrolladas durante el curso de Construcción de Software, con un enfoque en prácticas de desarrollo web.

## Descripción

Aquí se centralizan ejercicios, prácticas y entregas relacionadas con:

- Fundamentos de desarrollo web
- Implementación de interfaces
- Organización de proyectos
- Buenas prácticas de código
- Ejercicios de laboratorio del curso

## Objetivo

Documentar el progreso del curso y mantener un historial ordenado de los trabajos realizados durante las actividades prácticas.

## Contenido del repositorio

- Laboratorios del curso
- Actividades de desarrollo web
- Ejercicios prácticos
- Evidencias de aprendizaje

## Tecnologías y herramientas

Las tecnologías pueden variar según cada laboratorio, pero el repositorio puede incluir:

- HTML

- Herramientas de desarrollo web

1. Revisa el laboratorio o actividad que te interese.
2. Abre la carpeta correspondiente.
3. Sigue las instrucciones incluidas en cada ejercicio.
4. Verifica los resultados y el avance de cada práctica.
